# 🚗 Car Price Prediction using Machine Learning

## 📌 Project Overview

This project predicts the selling price of used cars using Machine Learning.

The complete Data Science workflow has been implemented including:

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Data Preprocessing
- Model Training
- Model Evaluation
- Feature Importance Analysis

---

## 📂 Dataset

The dataset contains various information about used cars such as:

- Present Price
- Driven Kilometers
- Fuel Type
- Selling Type
- Transmission
- Owner
- Manufacturing Year

A new feature **Car_Age** was created from the Year column.

Target Variable:

```
Selling_Price
```
